# Planning

This repository mirrors the [Byline specification](https://bylinespec.org) (upstream: [tgodier/byline](https://github.com/tgodier/byline)) for the authorship project.

Planning for the authorship repositories, including how Byline Feed implements this spec and where it diverges, lives in one place:

- [author-identity/.planning/SUITE.md](https://github.com/dknauss/author-identity/blob/main/.planning/SUITE.md) — cross-repo planning hub and release order
- [author-identity/docs/planning/spec-alignment-0.1.0.md](https://github.com/dknauss/author-identity/blob/main/docs/planning/spec-alignment-0.1.0.md) — spec divergences and decisions for Byline Feed 0.1.0

Changes to the specification text itself should go upstream first; see [CONTRIBUTING.md](CONTRIBUTING.md).
